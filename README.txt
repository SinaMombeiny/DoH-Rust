This is a DNS-over-HTTPS project built for Cloudflare Workers using Rust. It’s mostly for learning and testing rather than real production use. I already have two main projects that I actually use: https://github.com/SinaMombeiny/DoH-CFW and https://github.com/S-Privacy/DoH-vercel.This Rust version was just something I wanted to try to see how it feels compared to the JavaScript ones. I made it to experiment with Rust on Workers, test DNS query speed, look at the logs, and better understand what’s happening under the hood. It’s not meant to replace the other projects, just a side experiment. Feel free to check it out if you’re curious about writing Workers in Rust, but for actual daily use I’d still recommend the original ones.
